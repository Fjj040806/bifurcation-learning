Evidence supports a bounded model–observation interaction: exact orbit data may lack transverse information; small probes can be excellent with a correct dictionary but sensitive to noise; unconstrained NODEs benefit from broader excitation in these tested settings; local bifurcation type can be right while location remains shifted.

Important limitations: oracle acquisition anchors for radial controls; clean validation for noisy NODE experiments; coupled window/sampling/segment changes; incomplete optimizer convergence; a small number of acquisition seeds; selected local periodic points rather than complete global continuation; restricted extrapolation with a correct dictionary.
